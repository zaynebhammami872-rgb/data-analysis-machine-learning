# Data Analysis & Machine Learning with Python

## Project Overview

This project focuses on data analysis, data cleaning, data visualization, and machine learning using Python.

It was developed as part of my university learning journey in Management Information Systems, specializing in Business Intelligence.

## Objectives

- Explore and understand datasets.
- Clean and prepare data for analysis.
- Handle missing values and duplicate records.
- Detect and manage outliers.
- Perform statistical analysis.
- Apply machine learning algorithms.

## Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Contents

### 1. Data Cleaning & Exploratory Data Analysis

- Loading and exploring the dataset.
- Handling missing values.
- Removing duplicate records.
- Detecting and treating outliers.
- Data transformation and encoding.
- Statistical analysis.
- Data visualization.

### 2. Linear Regression

Applying Linear Regression to explore relationships between:
- Age and Salary.
- Salary and Monthly Expenses.
- Age and Monthly Expenses.

### 3. K-Nearest Neighbors (KNN)

Using the Iris dataset to explore classification with the KNN algorithm and evaluate model accuracy.

## Files

- `bdd.csv`: Original dataset used for data analysis.
- `projet_analyse.ipynb`: Jupyter Notebook containing the analysis and machine learning implementation.

## Learning Outcomes

Through this project, I practiced data preprocessing, exploratory data analysis, statistical methods, visualization, and basic machine learning techniques.
